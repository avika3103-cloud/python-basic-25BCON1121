# Python Factorial Calculator

A simple Python program that calculates the factorial of a number.

## 📌 Project Description

This project contains a Python program (`factorial.py`) that calculates the factorial of a given number.

The factorial of a non-negative integer `n` is the product of all positive integers less than or equal to `n`.

For example:

5! = 5 × 4 × 3 × 2 × 1 = 120

## ✨ Features

- Calculates the factorial of a number
- Simple and easy-to-understand Python code
- Handles user input
- Suitable for beginners learning Python

## 💻 Requirements

- Python 3.x

No additional libraries or dependencies are required.
